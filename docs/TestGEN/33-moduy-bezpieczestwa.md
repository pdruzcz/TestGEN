# **3.3.** Moduły bezpieczeństwa

### **3.3.1.** Przegląd modułów bezpieczeństwa

System TestGEN zawiera dwa kluczowe moduły bezpieczeństwa:

1.  **Moduł inteligentnej analizy luk w kodzie oprogramowania** -
    wykrywa podatności i generuje rekomendacje zabezpieczeń

2.  **Moduł analizy luk funkcjonalnych** - identyfikuje braki w
    implementacji i sugeruje rozszerzenia funkcjonalne
