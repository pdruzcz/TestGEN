# Podręcznik operatora systemu

## Wprowadzenie

Podręcznik dla operatora systemu. Opisuje obsługę codziennych operacji oraz ekranów monitoringu.

## Procedury operacyjne

WYM-001: Operator może uruchamiać codzienne raporty z ekranu operacji.

WYM-002: Operator może potwierdzać alarmy z listy zdarzeń.

WYM-003: System musi generować raport dzienny podsumowujący wszystkie operacje systemu przeprowadzone po zakończeniu każdego dnia roboczego.

WYM-004: System musi generować raport dzienny podsumowujący wszystkie operacje systemu przeprowadzone po zakończeniu każdego dnia roboczego.

## Obsługa alarmów

Kliknij przycisk Potwierdź na karcie alarmu, aby uznać alarm za obsłużony.

## Glosariusz

Operator: Użytkownik wykonujący codzienne operacje systemu.

Alarm: Sygnał o zdarzeniu wymagającym uwagi operatora.
