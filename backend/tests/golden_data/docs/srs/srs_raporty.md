# Specyfikacja wymagań modułu raportów

## Wprowadzenie

Specyfikacja wymagań dla modułu generowania raportów.

## Wymagania funkcjonalne

WYM-001: System musi generować raporty w formacie PDF oraz Excel.

WYM-002: Użytkownik może eksportować raport do pliku CSV.

WYM-003: System musi harmonogramować generowanie raportów okresowych.

WYM-004: System musi filtrować dane raportu według zakresu dat.

WYM-005: System musi zapisywać raporty w repozytorium plików.

## Wymagania niefunkcjonalne

WYM-010: Generowanie raportu musi trwać nie dłużej niż trzydzieści sekund.

## Glosariusz

Raport: Uporządkowane zestawienie danych w formie dokumentu.

Eksport: Zapisanie danych do pliku zewnętrznego formatu.
