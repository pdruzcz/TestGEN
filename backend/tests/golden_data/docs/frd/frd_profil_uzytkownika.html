Funkcjonalne wymagania profilu użytkownika

Wprowadzenie

Funkcjonalny dokument wymagań dla profilu użytkownika.

Wymagania funkcjonalne

WYM-001: Użytkownik może edytować dane swojego profilu.

WYM-002: Użytkownik może zmienić hasło do swojego konta.

WYM-003: System musi pozwalać na wgranie zdjęcia profilowego.

WYM-004: Użytkownik może ustawić preferowany język interfejsu.

Wymagania niefunkcjonalne

WYM-010: System musi zapewniać wydajność ładowania profilu poniżej jednej sekundy.

Glosariusz

Profil: Zbiór danych opisujących użytkownika w systemie.

Preferencja: Ustawienie wybrane przez użytkownika.
